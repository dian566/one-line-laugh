# The One-Line Laugh

Entry for the make.fun bounty [The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f).

The program writes one line to `/output/entry.txt`:

> My smart fridge put me on a diet without asking — now the ice cream hides behind the vegetables and judges me in Celsius.
